It is an AI Platform capable of hosting multiple AI-powered applications.

Applications are independent products.

Platform services are shared infrastructure.

Development Principles
Platform services never depend on applications.
Applications consume platform services.
Every application has its own gateway.
Every service owns its own database.
No shared Java utility library between services.
Communication through HTTP initially.
Event-driven architecture (RabbitMQ/Kafka) later.
AI Platform remains domain-agnostic.
Applications contain business logic; AI Platform contains AI capabilities.
Every service can be deployed independently.
